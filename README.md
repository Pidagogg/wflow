## What you can build

Connect a **trigger**, some **steps** and an **AI model** on a canvas, and W flow
runs it for you — on a schedule, when an e-mail or payment arrives, or when
another app calls it.

- **New Stripe payment** → add the customer to Google Sheets → thank them on Telegram
- **New e-mail with "Invoice" in the subject** → let AI pull out the amount → post it to Slack
- **Website form** → save it in Airtable → notify the team
- **Every morning at 8:00** → read your RSS feeds → AI summary → e-mail digest
- **A Telegram bot** that answers questions with your own AI model

## Why W flow

- **470+ nodes** — Gmail, Google Sheets, Drive & Calendar, Slack, Telegram, Discord,
  Notion, Airtable, Stripe, GitHub, HubSpot, databases, files, RSS, crypto and any REST API.
- **Bring your own AI** — OpenAI, Anthropic, Gemini or a local model, with spending
  limits, alerts and a cost preview, so an agent never surprises you with a bill.
- **One-click sign-in** to Google, Microsoft and other services — no API keys to paste.
- **See every run** — each node's input, output and duration, plain-language error
  codes, replay with the same data, and version history to undo any change.
- **Let your AI assistant build it** — Claude, Cursor or ChatGPT can create, check and
  run workflows through W flow's [MCP server](https://w-flow.tech).
- **Fair limits** — a run counts once, however many steps it has, so a 10-step
  workflow costs the same as a 1-step one. Pro is a flat monthly price.
- **Your data stays yours** — credentials are encrypted, hosted in Germany, and the
  whole builder can run on your own server.

## Get started

- **Cloud:** sign up at **[w-flow.tech](https://w-flow.tech)**. The free plan includes
  10 workflows and 50 runs a day. Pick a template or describe what you want and let the
  AI build it.
- **Your own server:** run W flow with Docker on your own machine — see
  [TECHNICAL.md](TECHNICAL.md). Self-hosting needs a Pro licence key from your
  account on w-flow.tech.

W flow is in **open beta**. Found a bug? [Open an issue](../../issues/new/choose) —
everyone whose report helps us fix something gets **a free month of Pro** once Pro
launches.
